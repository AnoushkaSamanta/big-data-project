# Ponytail Help

Quick reference card for all Ponytail modes:
- `/ponytail lite`: Build what's asked, name the lazier alternative in one line.
- `/ponytail`: Full ladder (YAGNI -> stdlib -> native -> one line -> minimum). Default.
- `/ponytail ultra`: Deletion before addition, challenges requirements before building.
- `/ponytail-review`: Review current diff for over-engineering.
- `/ponytail-audit`: Audit entire codebase for bloat.
- `/ponytail-debt`: Ledger of all `ponytail:` comments.
- `/ponytail-gain`: Measured benchmark impact scoreboard.
